# 🌐 Social Connect App – UI/UX Design

## 📌 Overview
</div>

Social Connect App is a mobile UI/UX design project created in Figma, focused on building a modern community-driven social networking experience.

The design emphasizes simplicity, usability, and engagement, allowing users to connect, share content, and communicate seamlessly through a visually appealing interface.

---
<div align = center>

## 🎯 Goals
</div>

- Design a user-friendly social platform
- Create a clean and modern UI
- Improve user engagement through intuitive flows
- Apply real-world UI/UX design principles
  
---
<div align=center>
  
## 🎨 Design System
</div>

- Color Style: Soft, modern, and engaging palette
- Typography: Clean and readable font hierarchy
- Layout: Grid-based and consistent spacing
- Components: Reusable UI elements for scalability
  
---
<div align = center>

## 🛠 Tools Used
</div>

- Figma – UI design & prototyping
- Component-based design system
- Mobile-first approach
